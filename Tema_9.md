## Задание 1
Допустим, что вы решили оригинально и немного странно познакомится
с человеком. Для этого у вас должен быть написан свой класс на Python,
который будет проверять угадал ваше имя человек или нет. Для этого
создайте класс, указав в свойствах только имя. Дальше создайте
функцию __init_ (), a в ней сделайте проверку на то угадал человек ваше
имя или нет. Также можете проверить что будет, если в этой функции
указав атрибут, который не указан в вашем классе, например,
попробуйте вызвать фамилию.


```python
class Elena:
    __slots__ = ['name']

    def __init__(self, name):
        if name == 'Елена':
            self.name = f"Да, я {name}"
        else:
            self.name = f"Я не {name}, а Елена"

person1 = Elena('Алексей')
person2 = Elena('Елена')
print(person1.name)
print(person2.name)

person2.surname = 'Петрова'
```

**Вывод:** Создание класса с помощью class позволяет описывать собственные типы данных, содержащие свойства и поведение. Использование __slots__ ограничивает набор допустимых атрибутов, предотвращая создание несуществующих свойств (например, surname). Таким образом, класс помогает структурировать данные и контролировать допустимые поля объекта.

## Задание 2
Вам дали важное задание, написать продавцу мороженого программу,
которая будет писать ДОбЗВИЛИ ли топпинг B мороженое и цену после
возможного изменения. ДЛЯ этого вам нужно написать класс, в котором
будет определяться изменили ли состав мороженого или нет. В этом
классе реализуйте метод, выводящий на печать «Мороженое с
{ТОППИНГ}» в случае наличия добавки, а иначе отобразится
следующая фраза: «Обычное мороженое». При этом программа должна
воспринимать как топпинг только атрибуты типа string. 


```python
class Icecream:
    def __init__(self, ingredient=None):
        if isinstance(ingredient, str):
            self.ingredient = ingredient
        else:
            self.ingredient = None

    def composition(self):
        if self.ingredient:
            print(f"Мороженое с {self.ingredient}")
        else:
            print('Обычное мороженое')

icecream = Icecream()
icecream.composition()
icecream = Icecream("шоколадом")
icecream.composition()
icecream = Icecream(5)
icecream.composition()
```

После написания класса BaM необходимо продемонстрировать что все

Также вас необходимо объяснить Пете почему на скриншоте ниже в

```python
class MyClass:
    def __init__(self, value):
        self._value = value
    
    def set_value(self, value):
        self._value = value
    
    def get_value(self):
        return self._value
    
    def del_value(self):

obj = MyClass(42)
print(obj.get_value())
obj.set_value(45)
```

## Задание 5
На разных языках здороваются по-разному, HO суть остается
одинаковой, люди друг с другом здороваются. Давайте вместе с вами
реализуем программу с полиморфизмом, которая будет описывать всю
суть первого предложения задачи. Для этого мы можем выбрать два
языка, например, русский и английский и написать для них отдельные
классы, в которых будет в виде атрибута слово, которым здороваются на
этих языках. А также напишем функцию, которая будет выводить
информацию O TOM, как на этих языках здороваются.
Заметьте, что для решения поставленной задачи мы использовали
декоратор @staticmethod, поскольку нам He нужны обязательные
параметры-ссылки вроде self.


```python
class Russian:
    @staticmethod
    def greeting():
        print("Привет")

class English:
    @staticmethod
    def greeting():
        print("Hello")

def greet(language):
    language.greeting()

ivan = Russian()
greet(ivan)
john = English()
greet(john)

```

![Результат](https://github.com/VernalisVentus/SoftwareEngineering/blob/theme_9/pics9/Рисунок5.png)

**Вывод:** Пример иллюстрирует полиморфизм - возможность использовать одинаковый интерфейс (greet(language)) для разных классов (Russian, English). Каждый класс реализует свой способ приветствия, но вызывается одинаковым образом. Это делает код гибким и расширяемым.

## Задание 1 (1-5)
Задание Садовник и помидоры.

```python
# Класс, представляющий один томат
class Tomato:
    # Словарь состояний томата с соответствующими описаниями
    states = {0: 'отсутствует', 1: 'цветение', 2: 'зелёный', 3: 'красный'}

    def __init__(self, index):
        # Уникальный индекс томата для идентификации
        self._index = index
        # Начальное состояние томата - "отсутствует" (0)
        self._state = 0  

    # Метод для роста томата на одну стадию
    def grow(self):
        # Проверяем, не достиг ли томат максимальной стадии зрелости
        if self._state < 3:
            self._state += 1  # Переходим на следующую стадию
        # Выводим информацию о текущем состоянии томата
        print(f"Томат {self._index} теперь {Tomato.states[self._state]}.")

    # Метод проверки, созрел ли томат полностью
    def is_ripe(self):
        return self._state == 3  # Возвращает True если томат красный

# Класс, представляющий куст томатов (коллекцию томатов)
class TomatoBush:
    def __init__(self, num):
        # Создаем список томатов заданного количества
        self.tomatoes = [Tomato(index) for index in range(1, num + 1)]

    # Метод для роста всех томатов на кусте
    def grow_all(self):
        print("\nКуст растёт...")
        # Проходим по всем томатам и вызываем метод grow для каждого
        for tomato in self.tomatoes:
            tomato.grow()

    # Метод проверки, все ли томаты созрели
    def all_are_ripe(self):
        # Используем функцию all() для проверки всех томатов
        return all(tomato.is_ripe() for tomato in self.tomatoes)

    # Метод сбора урожая (очистка списка томатов)
    def give_away_all(self):
        self.tomatoes.clear()  # Удаляем все томаты из списка
        print("Урожай собран")

# Класс садовника, который ухаживает за кустом томатов
class Gardener:
    def __init__(self, name, plant):
        self.name = name  # Имя садовника
        self._plant = plant  # Куст томатов, за которым ухаживает садовник

    # Метод для работы садовника (уход за растениями)
    def work(self):
        print(f"\n{self.name} ухаживает за растением.")
        self._plant.grow_all()  # Вызываем рост всех томатов
        print(f"{self.name} закончила работу.")

    # Метод сбора урожая
    def harvest(self):
        print(f"\n{self.name} проверяет урожай...")
        # Проверяем, все ли томаты созрели
        if self._plant.all_are_ripe():
            self._plant.give_away_all()  # Собираем урожай
            print(f"{self.name} собрала урожай.")
        else:
            print("не все томаты созрели!")  # Сообщение если урожай не готов

    # Статический метод - справочная информация (не требует создания объекта)
    @staticmethod
    def knowledge_base():
        print("""Справка по садоводству:
1. Томат проходит стадии: отсутствует - цветение - зелёный - красный.
2. Чтобы получить урожай, необходимо ухаживать за кустом до полного созревания.
3. После созревания все плоды можно собрат""")  # Опечатка: "собрат" вместо "собрать"

# Основная часть программы, которая выполняется при запуске скрипта
if __name__ == "__main__":
    # Выводим справочную информацию
    Gardener.knowledge_base()

    # Создаем куст с 3 томатами
    bush = TomatoBush(3)
    # Создаем садовника по имени Елена
    gardener = Gardener("Елена", bush)

    # Первый цикл ухода и проверки урожая
    gardener.work()    # Елена ухаживает за растениями
    gardener.harvest() # Проверяет, готов ли урожай

    # Второй цикл ухода и проверки урожая
    gardener.work()    # Продолжаем ухаживать
    gardener.harvest() # Снова проверяем урожай

    # Третий цикл ухода и проверки урожая
    gardener.work()    # Последний уход
    gardener.harvest() # Должны собрать урожай (все томаты созрели)
```

![Результат](https://github.com/VernalisVentus/SoftwareEngineering/blob/theme_9/pics9/Рисунок6.png)

**Вывод:** Инкапсуляция - приватные свойства _index и _state скрывают внутреннее состояние объектов;
Наследование не используется напрямую, но структура классов демонстрирует компоицию - один класс (Gardener) работает с другим (TomatoBush);
Полиморфизм проявляется в одинаковом интерфейсе работы с объектами Tomato;
Использование статческих методов (knowledge_base) показывает возможность вызова функций, не зависящих от конкретного экземпляра.
